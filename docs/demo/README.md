# Demo video / GIF

Drop your demo video or GIF of the device recognizing keywords in real time here (e.g. `demo.gif` or `demo.mp4`).

Then embed it in the top-level README, right under the photo strip at the top, e.g.:

```markdown
![Demo](docs/demo/demo.gif)
```

Tips for a good demo clip:
- Show all three LED states (recording → processing → result) in one continuous take.
- Include a couple of different keywords, plus one "noise/unknown" rejection.
- Keep it under ~15–20 seconds and under a few MB if using a GIF (GitHub renders GIFs inline in the README; for longer/higher-quality video, upload to YouTube and link/embed a thumbnail instead of committing a large file).
